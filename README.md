# Wawa TV

Client Twitch perso pour iPhone (Expo / React Native, TypeScript).

- **Suivis** : chaînes suivies gardées sur le téléphone (sans compte Twitch), directs en premier.
- **Parcourir** : directs et catégories les plus regardés.
- **Recherche** : chaînes et catégories.
- **Lecteur** : passe par des proxys européens sans pubs, choix de la qualité, image dans l'image, filtre lumière chaude, relance.
- **Chat** en direct (lecture seule, emotes Twitch).
- **Multi-stream** : 2 directs l'un au-dessus de l'autre, chat échangeable.
- **Contenus masqués** : chaînes, catégories, mots-clés.

## Installation

Chaque push sur `main` construit une IPA non signée et une Release.
Source FlareStore / SideStore : `https://github.com/nono7444/wawa-tv/releases/latest/download/altstore.json`
